A change is running when its run's status record says so: readiness reads the records beside the leases, and a record-only run carries `reportedBy` with no holder. `ready` names the directory and no author for such a run. A worktree on a branch named after an active change says whose it is (`belongsTo`), and the Pipeline tab draws that change once.
