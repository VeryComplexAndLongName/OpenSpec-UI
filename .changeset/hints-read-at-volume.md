A suggestion naming a dozen changes is now readable.

`maxSets` capped how many groupings were named and nothing capped the width of one, so twelve changes that could all run together produced a subject joining all twelve names with "and". Past a few, the rest are counted — "alpha, beta, delta and 9 more can run at the same time". The commands still name every change, because those are the work; it was the headline that had to be read rather than scrolled past.
