## 2. Icons

- [x] 2.1 A subset cut from the Metro icon font of the pinned 5.1.20 is

  Done on 2026-09-16, after the owner chose a cut subset over a subsetting
  library in the build.
  - **What is committed.** `icons-subset.woff`, 2,388 bytes, sha256
    `3d50a4a6…`; `icons-subset.json`, 293 bytes, the codepoint of each of the
    14 glyphs; `LICENSE`, MIT.
  - **What is not.** The published font (266,492 bytes) and its stylesheet
    (392,894 bytes) are no longer in the repository. The README records the
    package, the two file names and the command that cuts the subset again.
- [x] 2.2 `packages/webui/scripts/build-metro-icons.mjs` writes
  `packages/webui/src/metro-icons.generated.ts`: one `@font-face` whose `src`
  is a `data:` URI of the vendored subset, plus one class per glyph. It reads
  only the vendored pair, never `vendor/metro/metro.css`, and adds no
  dependency to the build.

  Done on 2026-09-16. The first attempt subset the font during the build with
  `subset-font`, which brought `fontverter`, `harfbuzzjs`, `wawoff2` and
  `woff2sfnt-sfnt2woff` into the tree. The owner refused that: the cut happens
  out of band and the result is committed, as the project site does it.
  - **Result:** 14 glyphs, subset 2,388 bytes, stylesheet 4,488 bytes. The
    generated module is byte-for-byte the one the subset already produced.
  - **The dependency is gone** from `packages/webui/package.json`, and
    `package-lock.json` is back to what `main` has.
  - **A name with no glyph fails the build**, naming it and pointing at the
    README, rather than writing a rule for a glyph the font does not hold.
- [x] 2.3 `packages/webui/src/icons.ts` exports `ICONS`, the map from a meaning

  `refresh`, `review`, `open`, `settings`, `agent`, `timeline`, `warning`,
  `ok` — to its glyph name, and `iconFor(meaning)`. A screen names a meaning;
