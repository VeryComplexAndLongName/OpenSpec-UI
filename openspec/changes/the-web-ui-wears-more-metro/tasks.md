## 2. Icons

- [ ] 2.1 The Metro icon font of the pinned 5.1.20 is vendored under
  `packages/webui/vendor/metro-icons/` with its licence and a README naming the
  source and the version, the way `vendor/metro/` records `metro.css`.
- [ ] 2.2 `packages/webui/scripts/build-metro-icons.mjs` writes
  `packages/webui/src/metro-icons.generated.ts`: one `@font-face` whose `src`
  is a `data:` URI of a subset holding only the named glyphs, plus one class
  per glyph. It does not read `vendor/metro/metro.css`.
- [ ] 2.3 `packages/webui/src/icons.ts` exports `ICONS`, the map from a meaning
  this product names — `change`, `spec`, `archive`, `task`, `run`, `stop`,
  `refresh`, `review`, `open`, `settings`, `agent`, `timeline`, `warning`,
  `ok` — to its glyph name, and `iconFor(meaning)`. A screen names a meaning;
  it never writes a `mif-` class.
- [ ] 2.4 `packages/webui/src/icons.test.ts` fails when `ICONS` names a glyph
  the generated module does not carry, and when the generated module carries a
  glyph nothing names.
- [ ] 2.5 `packages/webui/scripts/build-metro-icons.test.mjs` asserts the
  generated module matches a fresh run, the way `build-metro.test.mjs` does.
- [ ] 2.6 `packages/webui/src/components/Icon.tsx` renders
  `<span className={iconFor(meaning)} aria-hidden="true" />` and nothing else,
  so an icon never enters an accessible name.
