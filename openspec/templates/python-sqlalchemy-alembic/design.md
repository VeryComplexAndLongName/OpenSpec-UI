## Goals / Non-Goals

**Goals:**
- A single, importable `Base`/`engine`/session factory other modules can
  depend on.
- Migrations are the only way schema changes reach a real database —
  no implicit `Base.metadata.create_all()` in application startup.

**Non-Goals:**
- Not choosing an ORM query style (Core vs ORM session) beyond what this
  change's own models need — that is a project-wide decision to make
  separately if it does not already exist.
