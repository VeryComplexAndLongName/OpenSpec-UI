# Instructions for coding agents in this repository

The full instructions live in [`CLAUDE.md`](CLAUDE.md) — read that file, not
this one. This file exists only because some tools (GitHub Copilot's coding
agent among them) look specifically for `AGENTS.md` by that exact name and
do not know to look for `CLAUDE.md`.

Everything in `CLAUDE.md` applies here unmodified: it is not Claude-specific
in substance, only in its filename — a historical convention, not a scoping
decision. Do not fork or duplicate its content into this file; if it goes
stale, fix `CLAUDE.md`.

For the Agentic Harness specifically (stages, autonomy levels, review
gates, per-stage agents, and spending limits), see
[`HARNESS.md`](HARNESS.md) and [`LIMITS.md`](LIMITS.md) at the repository
root — pointers only; do not duplicate their content here either.

For how articles under `docs/articles/` are published (the canonical
article, the homepage repository that reads it, and every other venue's
manual, link-back-required copy), see
[`docs/articles/README.md`](docs/articles/README.md) — pointer only; do
not duplicate it here either.
