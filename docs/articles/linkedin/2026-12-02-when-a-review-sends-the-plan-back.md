## Post

Review found five things to fix. Running Propose again left every file as it was. The change already had a proposal, design, specs, and tasks.

Workbench gives those findings a route into the existing plan. A `changes needed` verdict runs one Update before Apply. The operator can also run `update plan` with a note of their own.

The example follows one requirement from the review into the spec, design, and task list.

Full write-up: https://openspec-ui.dev/articles/when-a-review-sends-the-plan-back/
