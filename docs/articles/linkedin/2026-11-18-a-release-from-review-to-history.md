## Post

A PR targets a release branch. CI passed yesterday, and a new commit landed this morning. What exactly are you reviewing?

OpenSpec Workbench 0.108.0 brings the committed diff and recorded verification into PR Review. It compares the change against the merge base with the PR target and tells you when a check belongs to an older commit. Copy PR summary carries those details into the PR description.

We also rebuilt the release calendar from GitHub, the standalone version history and npm. You can now see each version on the day it shipped, including days with several releases.

Full write-up: https://openspec-ui.dev/articles/a-release-from-review-to-history/
