## Post

A green checkout job is a useful result. Which requirement scenario is it meant to exercise?

In OpenSpec Workbench PR Review, refresh the checks for the published commit, select a scenario and one of its reported checks, then preview the diff before saving the association to scenario-checks.json. A teammate can review that mapping with the proposal. The check's run link is where you can inspect what actually ran.

The article walks through the postal-code example and explains which results Workbench reads from GitHub, GitLab and Gitea.
