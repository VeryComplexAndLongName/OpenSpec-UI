## Post

A PR is waiting for a required check. The local tests passed. What did GitHub actually record for the published commit?

OpenSpec Workbench 0.109.0 adds **Refresh GitHub checks** to PR Review. It shows the reported states and run links alongside the checks the target branch expects. **Copy PR summary** carries the report into the pull request.

This release also links OpenSpec scenarios to named checks and previews the specification changes an archive would produce. **Open Example** lets you try the review with a sample change.

Full write-up: https://openspec-ui.dev/articles/when-a-pr-check-has-no-result/
