## Post

One card on the board. Four calls to agents. The old cost report could count just the first.

A Harness chain shares its run ID across stages and retries. Workbench now gives each recorded invocation its own ID, keeps the token categories, and says how many calls actually reported a dollar amount.

Two calls might report $0.02 and $0.00 while two report tokens only. The report can show $0.02 with coverage for two of four calls. Retained logs can still answer the question after the change is archived.

Full write-up: https://openspec-ui.dev/articles/what-one-run-actually-spent/
